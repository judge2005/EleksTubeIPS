Install EleksTubeIPS firmware

Version $version$ of $repository$, replacement firmware for the EleksTube IPS clock and its clones. Flash it to your clock over USB from this page.

This browser can't connect to USB devices. Open this page in Chrome or Edge on a computer.

1Before you start

  • Use Chrome or Edge on a computer. Phones and most other browsers can't connect to USB devices.
  • Connect the clock to the computer with a USB cable that carries data, not just power.
  • To keep a copy of the clock's original firmware, back it up with esptool.py first. This page can't. The installation guide shows how.

2Choose your clock

Clock

Some clocks sold as an EleksTube IPS V2 need the V1 firmware. If every display shows the same digit after installing, install the other EleksTube version with Upgrade. Your settings are kept.

3Install

Upgrade

For a clock that already runs this firmware, 1.9.4 or later. Installs only the firmware, so your settings, Wi-Fi details and uploaded images are kept.

When asked, leave Erase device unticked. Erasing removes everything, and the clock won't start again until you do a full install.

Needs Chrome or Edge on a computer. Needs an HTTPS page.

Full install

For a clock running its original firmware, or to start over. Also installs the default clock faces, weather icons and slide shows, replacing any you've uploaded.

On a first install, tick Erase device when asked. Leave it unticked to keep your settings and Wi-Fi details.

Needs Chrome or Edge on a computer. Needs an HTTPS page.

Choose your clock to turn on these buttons.

4Connect to Wi-Fi

If the clock doesn't have your Wi-Fi details yet, Connecting to WiFi in the wiki walks you through it. After that, open the clock's web page to set it up.

Prefer the command line? Download the files from the $version$ release and flash them with esptool.py as the installation guide describes.

Installs use ESP Web Tools.
